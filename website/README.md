# AsterMax Product Website

Marketing and product-vision site for AsterMax.

## Preview

Open `index.html` directly in a browser or serve the directory with any static HTTP server.

```bash
cd website
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Included brand assets

- `assets/astermax-logo.svg` — primary horizontal brand logo.
- `assets/astermax-icon.svg` — square application/icon mark.
- `MARKETING.md` — positioning, taglines, audiences, product pillars, social copy and accuracy policy.

## Accuracy boundary

The website intentionally distinguishes **current development** from **future product vision**. AI-guided modelling, standards interpretation, adaptive fidelity and multiphysics are roadmap concepts unless separately marked as implemented and numerically validated in the main AsterMax capability ledger.

> **AI proposes → the model is explicit → the engineer decides → the solver executes → benchmarks verify → AI interprets.**
