# Harness policy changes

Policies in this directory govern what may be accepted as evidence and how self-improvement is evaluated.

A policy change is not an ordinary feature change. It must be isolated from the feature WorkPackage that benefits from it, reviewed independently, and evaluated against a preserved baseline. A candidate is not allowed to weaken the rule that judges the candidate.

For self-improvement experiments, retain both baseline and candidate manifests, the frozen suite hash, resource budget, mandatory failures, aggregate score, and final human decision.
