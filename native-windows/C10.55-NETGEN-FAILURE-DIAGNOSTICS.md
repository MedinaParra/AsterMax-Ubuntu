## C10.55 diagnostic requirement before further optimization
Instrument the NetGen invocation without changing geometry semantics. On every CAD tessellation failure capture:

1. executable absolute path;
2. exact argument vector (quoted safely);
3. working directory;
4. input BREP absolute path, existence and byte length;
5. process exit code;
6. elapsed process time;
7. stdout and stderr separately;
8. expected output paths, existence and byte length;
9. preserve/copy the failed temporary job directory to an audit directory instead of deleting it;
10. distinguish timeout, process-start exception, non-zero exit and zero-exit/missing-output.

Do not log user document contents. Do not claim a speedup from diagnostic instrumentation.
